# The Lacrum Group app (free starter)

This is a small Progressive Web App (PWA) starter for The Lacrum Group.

## Run it locally
Open `index.html` in a browser to preview the app. Some install/offline features require HTTPS or localhost.

## Publish for free
You can host these static files on a free static-hosting plan, for example GitHub Pages:
1. Create a GitHub account and a new public repository.
2. Upload all files in this folder to the repository root.
3. In repository Settings -> Pages, choose deploy from the `main` branch and `/ (root)`.
4. Wait for the site URL to appear. Open it on your phone using Safari (iPhone) or Chrome (Android).
5. Use the browser's Add to Home Screen / Install option.

A free hosting provider may change its limits or terms. A custom domain is optional and usually costs extra. An installable PWA is not the same as an App Store listing.
